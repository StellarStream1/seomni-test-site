What Is A Test Page?

A test page is a page published only to confirm that a publishing pipeline works end to end, from the editor to the live site.

How Does Publishing Through GitHub Work?

SEOmni opens a pull request with the new file. Nothing changes until the site owner merges it, then GitHub Pages deploys the site.

  • SEOmni writes the page.
  • The owner reviews the pull request.
  • Merging publishes it.

FAQs

Does anything go live before merging?

No. The page only goes live after the pull request is merged and the site deploys.
